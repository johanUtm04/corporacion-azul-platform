# Corporación Azul Platform

Corporate web platform designed to centralize and organize information about products, brands, branches, services, and company content.

The project is being developed as a modern web platform with a decoupled architecture, separating the frontend, backend, data layer, and content management system.

## Project Status

Version: v0.1

Current phase: Initial architecture and repository setup.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Laravel
- REST API

### Database
- PostgreSQL

### Cache
- Redis

### Content Management
- Headless WordPress
