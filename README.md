# Corporación Azul Platform

Corporate web platform designed to centralize and organize information about products, brands, branches, services, and company content.

The project is being developed as a modern web platform with a decoupled architecture, separating the frontend, backend, data layer, and content management system.

## Project Status

Version: v0.1

Current phase: Initial architecture and repository setup.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Laravel
- REST API

### Database
- PostgreSQL

### Cache
- Redis

### Content Management
- Headless WordPress

## Repository Structure

```text
corporacion-azul-platform/
├── frontend/
├── backend/
├── docs/
│   ├── architecture/
│   ├── requirements/
│   └── decisions/
├── .gitignore
└── README.md
```

### Directory Responsibilities

- `frontend/`: Contains the public web application built with React and TypeScript.
- `backend/`: Contains the Laravel application and REST API.
- `docs/architecture/`: Contains architecture documentation and C4 diagrams.
- `docs/requirements/`: Contains functional and non-functional requirements.
- `docs/decisions/`: Contains Architecture Decision Records (ADRs) and other relevant technical decisions.
- `.gitignore`: Defines files and directories that Git should not track.
- `README.md`: Provides the main overview, setup information, and documentation entry point for the project.
